# analyzesec-site

Marketing site for AnalyzeSec. Plain HTML, CSS and JavaScript, no build step.

## Files

- `index.html`: page structure and copy
- `styles.css`: tokens, layout, tabs, mockups, responsive rules
- `main.js`: hero glyph canvas, headline scramble, accessible tabs
- `assets/`: product screenshots (WebP) with alt text in `index.html`

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Before deploy

- Replace `YOUR_FORM_ID` in the form action in `index.html` with the Formspree form ID.
- Connector names are text labels. No third-party logos are used.
